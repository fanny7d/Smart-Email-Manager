# Support

Use GitHub Discussions for setup and usage questions, and GitHub Issues for reproducible defects or
accepted feature work. Security vulnerabilities must use private reporting as described in
[SECURITY.md](SECURITY.md).

When requesting help, include:

- application version and deployment method;
- operating system, Python, PostgreSQL, Node.js and pnpm versions;
- the failing command or API operation;
- sanitized logs and reason codes;
- whether the issue reproduces without a proxy.

Never post passwords, OAuth refresh tokens, API tokens, mailbox contents, private email addresses or
unencrypted configuration files.
